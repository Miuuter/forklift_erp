# 维护风险登记表

| 风险 | 影响 | 处理顺序 | 验证方式 |
| --- | --- | --- | --- |
| 库存流水、余额、FIFO 批次或兼容缓存不一致 | 库存和成本失真 | P0 | 闭环校验、FIFO 尾差、并发调拨和冲销测试 |
| 收付款/冲销重复写入或来源错配 | 财务和应收失真 | P0 | 同请求 ID 并发、冲销链、日对账测试 |
| 批量事务出现部分提交 | 业务状态不可恢复 | P0 | MySQL 事务回滚、版本冲突和批量竞争测试 |
| 导入任务超时后被重复执行 | 重复主档或重复账务 | P1 | 状态机、恢复、重复确认和失败重试测试 |
| 附件元数据与文件不一致 | 合同/发票无法追溯 | P1 | 上传、权限、备份、恢复和缺失文件测试 |
| 前端请求缓存或刷新不完整 | 页面显示旧数据 | P1 | 写入后刷新、冲突提示和模块 E2E |
| 构建依赖本机 Git 配置 | CI/本地构建结果不一致 | P1 | 无用户级配置环境下执行 Maven |
| 大型服务和入口文件继续膨胀 | 修改容易引入回归 | P2 | 质量门禁、模块边界和增量拆分审查 |

本表只登记维护风险，不把多行单据、退货、二维码或提醒等新增业务列入本轮范围。
